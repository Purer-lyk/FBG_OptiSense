OptiSense Beta 软件与USB固件更新助手
客户端：v1.0.8 Beta；固件：v1.0.118 Beta
适用环境：Windows 10/11 64位，不需要安装Python，不需要联网。

使用方法
1. 把收到的 OptiSense_Beta_Update.exe 保存到本地文件夹并运行。
   助手内部已包含签名清单、完整Beta软件和固件，无需另选下载文件。
2. 保存光谱记录并关闭OptiSense客户端。
3. 确认安装目录含 FBG_OptiSense_Studio.exe，点击“一键更新软件”。
   默认是当前用户的 LocalAppData\Programs\FBG OptiSense Studio；装在其他位置时手动选择。
   若电脑尚未安装客户端，需先安装已有Setup；本助手不是首次安装器。
4. 若还需要升级板卡，将对应解调仪用USB连接并持续供电，选择设备后点击“一键更新固件”。
   软件与固件是两个独立操作；只更新软件不会刷写板卡。
5. 更新期间不要关助手、拔USB或断电。完成后重新打开客户端。
   已经达到或高于包内版本时显示“已是最新版本”，不会重刷或降级。

允许更新的板卡
二号机：395736523033
三号机：207933893232
四号机：207A33813232
按STM32原生USB唯一编号识别，不依赖COM号；其他编号不会被本包刷写。
设备必须已具备兼容USB升级协议（v1.0.105起）和引导程序。
更老且不支持USB更新的设备，需由开发人员先用CMSIS安装配套引导和应用。
助手会核对设备编号、引导状态、固件版本、签名和文件完整性；不满足条件则拒绝更新。

记录与回退
更新软件前保留原安装目录的备份，并保留用户数据和卸载程序。
Beta使用独立用户目录 LocalAppData\FBGOptiSenseStudioBeta。
首次默认启动会复制缺失的旧正式版设置和分机记录；不覆盖已有Beta记录，不删除正式版记录。
旧便携版保留的outputs也留在安装目录及备份中，但非标准旧版本的资料位置可能需要人工迁移。
更新失败时不要删除备份；联系开发人员处理。请勿把机器一的校准文件复制给其他机号。

Beta范围与注意事项
固件统一40摄氏度温控，保留USB更新、USB/LAN数据采集和故障停光，删除网络OTA。
v1.0.118已在三、四号机烧录及USB零电流验证；本包尚未在二号机现场验证这版。
这些结果不是光学精度或所有机器校准验收。四号机仍缺专属2001点校准表，不能借用别机表采光谱。
开发者模式默认关闭，界面中的采集/诊断功能仍需要正确校准和安全光路。
收到文件应通过可信渠道核对SHA256。助手内的更新载荷使用Ed25519签名；
Windows可能提示未知发行者，这不等于程序具有Windows Authenticode发行证书。
不要将开发者源码包或原始校准记录转发给普通客户。
